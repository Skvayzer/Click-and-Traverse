The correction has five parts:

1. Room occupancy marks every voxel cell that intersects the canonical oriented box geometry. Exact separating-axis tests include thin rotated parts without blanket obstacle dilation. All 13 omitted legs are represented after rebuilding.
2. Room navigation follows ordered route segments stored in episode state. It cannot jump to a globally nearby later segment. It advances around a corner only after a continuous swept-cylinder visibility check; otherwise it returns toward its current segment or stops. True and delayed actor queries share the same waypoint. Commands and horizontal body-guidance rewards follow that route. Local CAT vertical shaping, boundary/SDF observations, and hand/elbow protection remain.
3. A continuous swept trunk-cylinder check detects crossing between successive control positions, including thin tabletops. This room-only failure has no initial grace period and invalidates goal credit. Success also requires ordered final-route completion. The proxy has radius 23 cm and world-height interval 35–105 cm; it does **not** certify complete articulated body clearance or physical obstacle contact dynamics.
4. Route state resets with each episode. A room can resume walking when a temporarily blocked route becomes visible; native CAT's permanent stop latch is retained for CAT scenes.
5. Transitions into or out of rooms reset task history and the complete simulator state together. Previously, stale head/hand/foot positions from another scene could manufacture large velocity features on the first subsequent step. Native CAT-to-CAT reset semantics and adaptive sampler bookkeeping remain unchanged.
